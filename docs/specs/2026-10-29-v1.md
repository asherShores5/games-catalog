# Games Catalog v1 spec

Date: 2026-10-29. Terms are defined in `GLOSSARY.md`.

## Problem

My games are spread across Stores, Accounts, Platforms and discs. I want one master list and
to type a name and see where I own it, and to filter by what kind of game it is (co-op,
narrative, open-world…) when choosing what to play.

## Decisions

- **Users**: just me. One owner, own Cognito user pool, no sharing.
- **Hosting**: `games.ashershores.com`, same personal AWS account and Route 53 zone as Honey Do,
  separate stacks. Deploy CI through GitHub OIDC comes later.
- **Stack**: mirrors Honey Do (TS npm workspaces `shared`/`api`/`web`/`infra`, CDK, Lambda +
  DynamoDB, PWA, vitest).
- **Model**: Game has many Copies. A Copy has Platform, Format, optional Edition, and an Account
  when Digital. Accounts are a managed list (Store + nickname). Platforms are an editable list,
  seeded with common ones. Editions never split a Game; I can merge duplicate Games by hand.
- **Ownership**: Owned is derived (at least one Copy). Adding a Copy to a Wishlist Game clears
  Wishlist and sets Play status to Backlog. Removing a Copy just deletes it (no sold/lent states).
- **Tags**: attach to Games. One shared, editable list (rename, merge, delete) for imported and
  manual Tags. Each Game–Tag link records its Tag source. A re-Import never removes a manual
  Tag and never re-adds an imported Tag I removed. Seeded common Tags: single-player, co-op,
  versus, narrative, open-world, platformer.
- **Filtering**: name search plus filters for Tags (AND: every selected Tag), Platform,
  Wishlist / Owned, and Play status, all combinable. Filter state lives in the URL.
- **Search**: case-, punctuation- and accent-insensitive substring match, instant, client-side.
- **Steam Import**: a manual "Import from Steam" button per Steam Account. Uses `GetOwnedGames`
  (API key in Secrets Manager; Steam ID stored as Account data, never in the repo). Games are
  matched by Steam app ID, so re-runs are idempotent. Tags come from Steam store Categories and
  Genres, mapped onto common Tags (e.g. Online PvP → versus, Co-op → co-op); unmapped ones are
  imported as-is. Shows a summary of added and already-present Games. Other Stores are manual.
- **Steam Categories**: store-feature Categories (achievements, cloud saves, trading cards,
  partial controller support, Remote Play on phone/tablet/TV, accessibility options…) are on an
  ignore list and never become Tags. Two are let through as Tags because they help choose what
  to play: "Full controller support" and "Remote Play Together".
- **Imports respect my Tag edits**: an Import puts a store Tag on the Tag with that name now,
  else on the Tag that used to have it (renamed) or absorbed it (merged). A Tag I deleted is
  never re-created by an Import, unless I create a Tag with that name again myself.
- **Seed**: one-time import of the 29 rows on the Notion "Gaming catalog" page. "Not owned" →
  Wishlist Game. "Owned" → Game with an Unknown Copy. "Playing" → same, plus Play status
  Playing. The Notion page is left alone; the app is the source of truth.

## Out of scope for v1

Other Store imports (Epic, GOG, PSN, Xbox, Nintendo); SteamSpy community tags; IGDB or other
metadata; Steam header art (later); scheduled Imports; lending/sold tracking; OR tag filters;
two-way Notion sync; multiple users.

## User stories

1. I search "witcher" and see The Witcher 3 with every Copy (Platform, Format, Account, Edition).
2. I add a Game by hand with a PS5 Physical Copy.
3. I add a Digital Copy and pick its Account from my Account list.
4. I create, rename and delete Accounts and Platforms.
5. I import my Steam library into "Steam: main" and see what was added.
6. I re-run the Import and nothing is duplicated; my manual Copies and Tags are untouched.
7. Imported Games arrive with mapped Tags (co-op, versus, single-player…).
8. I add, remove, rename and merge Tags; Imports respect my removals.
9. I filter by co-op + open-world on PC and see only Games with both Tags and a PC Copy.
10. I filter to my Wishlist, or by Play status.
11. I buy a Wishlist Game, add its Copy, and it leaves the Wishlist as Backlog.
12. I merge two Games that are really one title; their Copies and Tags combine.
13. I fill in the Platform/Format of a Seeded Game's Unknown Copy.
14. I sign in once on my phone and the PWA keeps me signed in.
